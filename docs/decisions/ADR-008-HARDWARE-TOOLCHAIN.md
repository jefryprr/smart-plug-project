# ADR-008 — Hardware Toolchain and Source of Truth

**Status:** Accepted with deviations
**Date:** 2026-11-15

## Context
The PRD prefers KiCad, Circuit-Synth, WireViz, CadQuery, and FreeRouting. In this environment:
- KiCad/KiCad CLI: **not installed**
- Circuit-Synth: **not used**
- WireViz: installed in `.venv`, Graphviz portable downloaded
- CadQuery: installed in `.venv`
- FreeRouting/JDK: FreeRouting not installed; manual routing not done

## Decision
- Use **KiCad native files** generated by `hardware/generators/generate_kicad.py` as a **system block schematic** and a **placement-only PCB**. Mark ERC/DRC/Gerber `BLOCKED`.
- Use **WireViz** for harnesses (6 rendered YAMLs).
- Use **CadQuery** for parametric enclosure/assembly (STEP/STL/render).
- Do not fake Gerber, DRC, ERC, or 3D KiCad renders.
- The source of truth for the block schematic is the generator + YAML; for mechanical, the CadQuery source + `parameters.yaml`.

## Consequences
- No manufacturing release.
- Native KiCad files parse with `kiutils`, but were not opened in KiCad.
- Circuit-Synth deviation documented; no Python-to-KiCad claim.
- A future KiCad install must re-run ERC/DRC and regenerate manufacturing artifacts.

## Alternatives
- Hand-write Gerber: rejected as fake.
- Skip KiCad: rejected because native files are required.
- Use FreeRouting: not applicable without a routed board.
